# Recorded table sounds

These recordings are distributed under **CC0 1.0 Universal**, separately from the
project's MIT-licensed code. See `LICENSE-CC0.txt` for the dedication and disclaimer.
Attribution is not required by CC0; these credits acknowledge the contributors.

| File | Credit | Use |
| --- | --- | --- |
| `dice-roll.wav` | OldJobobo | Full dice tumble in the Book |
| `dice-roll-short.wav` | OldJobobo | Shorter dice tumble on the Table |
| `dice-land.wav` | OldJobobo | Impact and settling, played once when the chosen animation lands |
| `page.wav` | Owlish Media | Page turn when the GM speaks |

OldJobobo recorded the dice and dedicates those recordings to the public domain
under CC0 1.0 Universal. The page-turn recording was supplied by OldJobobo as CC0,
with credit to Owlish Media; `page.wav` is the short playback edit already used
locally, not a replacement recording. Page playback uses 75% volume on PipeWire
and PulseAudio without changing the audio file.

The dice are stereo 16-bit PCM at 48 kHz; the page turn is stereo 16-bit PCM at
44.1 kHz. No conversion tools, downloads or network access are needed at runtime.
Other table sounds remain synthesized with the Python standard library.
